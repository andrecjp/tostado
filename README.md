# Tostado Landing Page

Revisa la página web [aquí](https://andrecjp.github.io/tostado/).

Tostado es una cafetería ficticia enfocada en café de especialidad y galletas. Esta se creó como parte de un proyecto de branding realizado en conjunto con Almendra González, el cual puedes revisar en [Behance](https://www.behance.net/gallery/234618649/Tostado-Branding-Cafeteria).

Este proyecto es una maqueta de landing page para invitar a clientes a suscribirse al newsletter de la cafetería.
